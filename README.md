🎯 Objective

The goal of this project is to learn collaborative development with Git & GitHub by building a simple but structured webpage using HTML, CSS, and JavaScript, where each member contributes to a different part of the project.

🧠 Learning Outcomes

Understand Git and GitHub collaboration (clone, pull, push, commit).

Work together on different parts of a single project.

Learn how HTML, CSS, and JavaScript integrate.

Practice real teamwork on a frontend project.

🛠 Tools & Technologies

HTML5 – for structure

CSS3 – for styling

JavaScript ES6 – for interactivity

Git & GitHub – for version control

Visual Studio Code – as the editor
